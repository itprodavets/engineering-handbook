## Пять ступеней одного механизма

Учись по цепочке **направление → модуль → подробный раздел → самостоятельный эксперимент → проверка глубины → повторение пробелов**. Каждая техническая идея имеет **одно каноническое объяснение**, а вопросы и лаборатории ссылаются на него.

В образцовом модуле [Async/Await](../topics/dotnet/async-lifecycle.md) теперь **шесть последовательных разделов**: I/O и CPU → контракт awaiter → компиляторская state machine → сетевой I/O → выделения памяти → production-диагностика. Каждый подробный раздел включает пояснения на RU и EN, код, потребляемые ресурсы, граничные случаи и критерии проверки.

## Как подтверждать знания

| Уровень | Что нужно сделать |
|---|---|
| **Recall** | Дать точное определение и назвать ограничения |
| **Explain** | Рассказать механизм C# → Roslyn → CLR/JIT → ОС |
| **Predict** | Предсказать результат незнакомого кода до запуска |
| **Diagnose** | Найти вероятную причину и проверить её по метрикам/трассировке |
| **Design** | Выбрать production-решение и обосновать компромиссы |

Сначала **напиши ответ**, затем раскрой критерии, потом оцени себя: «Пока не могу / Частично / Могу обосновать». Оценки — **самооценка**, а не сертификация. Настоящая проверка Predict/Diagnose/Design требует исполнения кода и данных измерений. [Методика технического собеседования](engineering-interview.md).

## От ошибок к карточкам

Когда ставишь «Пока не могу» или «Частично», система создаёт **карточку именно для проблемного навыка**. Карточки из банка вопросов открываются **после того, как отмечен изученным соответствующий раздел**; ранее начатые повторения не теряются.

**Не знаю:** повторить через 10 минут. **Знаю:** интервалы 1, 3, 7, 14, 30, 60, 120, 240 дней; максимум 10 новых карточек в день. Это простой scheduler, **не Anki FSRS**.

## Хранение данных

Публичные: `content/units.json`, `content/questions.json`, `labs/<track>/`, генерируемые Markdown и Pages. Личные: `eh:units:v1`, `eh:mastery:v1`, `eh:mastery-drafts:v1`, `eh:srs:v1` в localStorage браузера. Синхронизации между устройствами пока нет; очистка браузера может удалить прогресс. Оценки в Google Таблице отдельно от публичного репозитория.

## Для разработчика материалов

Изменяй **исходные** `content/units.json` и `content/questions.json`, затем запускай:

```bash
python3 scripts/build_site.py
python3 scripts/build_units.py
python3 scripts/build_site.py --check
python3 scripts/build_units.py --check
python3 scripts/check_site.py
python3 scripts/check_links.py
node --test tests/spaced-repetition.test.mjs tests/mastery.test.mjs
python3 scripts/check_deep_labs.py   # .NET 10 SDK требуется
```
