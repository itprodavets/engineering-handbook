# Как пополнять Engineering Handbook прямо из чата

[Русский](chat-authoring.md) · [English](chat-authoring.en.md)

[Главная](../README.md) · [Каталог](../topics/dotnet/README.md) · [Правила точности](technical-accuracy.md)

**Тебе не нужно вручную создавать Markdown, JSON и C#-файлы.** Просто напиши в нашем чате, например:

> Добавь в Engineering Handbook тему **Go scheduler (G/M/P)**. Проверь, что она не дублирует существующую. Нужны RU/EN, точное объяснение runtime и ОС, два вопроса и один запускаемый пример с тестом.

Или:

> Добавь этот фрагмент C# как задачу с подвохом к теме ThreadPool, со скрытым ответом и объяснением выделяемых ресурсов. Проверь код и добавь его в сайт.

Или:

> Уточни определение в теме Q-009 по исходникам .NET 10, исправь ошибки, обнови обе версии языка, затем проверь сборку.

## Что изменится в репозитории

1. Сначала проверяются основные темы в [`content/lessons.json`](../content/lessons.json), чтобы не создать повторное объяснение.
2. Затем дополняется существующая тема или добавляется уникальная новая с `track`, `stage`, двуязычными текстами и первоисточниками.
3. Новые вопросы получают следующий свободный постоянный ID `Q-###` и хранятся в [`content/questions.json`](../content/questions.json). Для каждого указан **один** основной урок.
4. Если есть запускаемый код, добавляется настоящий пример в `labs/<track>/`, а не только картинка результата. Для .NET — `dotnet run --file labs/dotnet/Q-###.cs`.
5. Генератор создаёт русские и английские Markdown, ссылки в README и данные интерактивного GitHub Pages. Исправления вносятся **в JSON-источники**, не в сгенерированные страницы.
6. Проводятся проверки ссылок, структуры, локализации и кода; изменения фиксируются в GitHub с ссылкой на конкретную тему и коммит.

## Правила организации

- **Одна тема — одно эталонное объяснение:** например, устройство ThreadPool описывается в одной теме, остальные вопросы только ссылаются на неё.
- **Теория и закрепление — отдельно.** Вопросы проверяют понимание; лаборатории позволяют воспроизвести поведение и измерения.
- **RU / EN раздельно:** язык меняется в интерфейсе, текущая тема сохраняется.
- **Точные гарантии:** версии C#/.NET/Go и платформы указываются, если от них зависит результат. Не подменяем измерения произвольными цифрами.
- **Не публикуем личное:** ответы, оценки, секреты и приватные проекты не попадают в GitHub; личный прогресс — в отдельной Google Таблице или локально в браузере.

## Технические команды

```bash
python3 scripts/build_site.py
python3 scripts/build_site.py --check
python3 scripts/check_site.py
python3 scripts/check_links.py
node --check site/assets/app.js
python3 scripts/check_labs.py  # если доступен .NET 10 SDK
```
